# Фаза 0: валидация (10 интервью)

## Цель
Проверить, готовы ли подростки/родители платить за roadmap + AI-risk до масштабирования.

## Кого спрашивать
- 7 человек 15–19 (школа / первый курс)
- 3 родителя или классный руководитель

## Скрипт (15 мин)
1. Покажи демо на `/demo` — 2 минуты молча смотрят.
2. «Понятно ли, куда идти после этого?» (1–10)
3. «Поверил бы цифрам AI-risk? Почему да/нет?»
4. «Заплатил бы 299₽/мес за PDF для родителей + без лимита?» (да / нет / сколько)
5. «Чего не хватило в симуляции?»

## Запись
Дублируйте в [`INTERVIEW_LOG.md`](./INTERVIEW_LOG.md) с колонкой P0.

## P0 после 5 интервью
Список 3–5 правок для дней 8–9 (пример: «AI-risk непонятен» → tooltip на results).

## Критерий go
- ≥6 из 10 ставят понятность ≥7
- ≥3 готовы заплатить или назвали цену ≥199₽
